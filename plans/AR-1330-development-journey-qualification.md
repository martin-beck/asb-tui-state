# AR-1330 — Development credential journey qualification

Qualify a disposable, credential-free development journey from clean TUI install
through enrollment, provider/model selection, agent defaults, mock capture,
strict offline replay and comparison. Record exact ASB/asb-tui revisions and
label every result as development/mock evidence.

This is the prototype release gate; it does not prove production authentication,
secret storage or external-provider reachability.
