# AR-1221: asb-tui benchmark-readiness tutorial

Create the TUI tutorial for checking whether the selected agent and current configuration are usable
for benchmarking. Cover readiness/capability results, unavailable or incomplete configuration,
credential-reference refusal, platform constraints, and the distinction between checking readiness
and running work.

CI validates navigation/action syntax, formal state transitions, response fixtures, and refusal
explanations offline. It never starts ASB, an agent, or an LLM connection.
