# AR-1623 — dev-channel release, upgrade, and rollback gate

Qualify the TUI and paired ASB install on clean machines and disposable user
directories. Verify default `dev` and explicit channel selection, latest main
heads, wizard restart persistence, upgrade preservation, rollback restoration,
and actionable rejection of stale or tampered artifacts. Record exact commits,
bundle digests, hosted checks, and fresh downstream consumption.

This is a development-prototype release gate; development credentials and
signatures remain warning-only under AR-1621.
