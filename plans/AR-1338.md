# AR-1338 — End-to-end first-class benchmark journey qualification

## Scope

Qualify the complete standalone asb-tui journey: user-driven setup, provider
and model selection, benchmark-pool and measure selection, ASB configuration
materialization, preflight, launch, live statistics, final results, and report
comparison. Publish one reproducible development qualification command and
support matrix.

## Dependencies

Depends on AR-1333, AR-1334, AR-1335, AR-1336, AR-1337, and AR-1339.

## Acceptance

- A disposable user completes the supported journey using visible selections
  only; no documentation lookup, argument copying, or manual path editing is
  required.
- A clean user can run `asb tui install` and then `asb tui` to launch the
  installed application, with truthful status and recovery on missing or
  incompatible bundles.
- Fresh private state, absent credentials, and denied network produce a full
  deterministic development fixture journey with explicit provenance labels.
- Version, catalog, bundle, protocol, configuration, and runner mismatches stop
  before execution and expose exactly one actionable recovery choice.
- A PTY/TUI transcript or equivalent bounded interaction evidence covers setup,
  selection, preflight, running statistics, final results, and comparison.
- Exact source SHA, generated configuration digests, fixture identities,
  command logs, exit codes, and hosted checks are recorded; the result must not
  be described as live-provider or production qualification.
