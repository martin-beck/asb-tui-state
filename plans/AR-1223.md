# AR-1223: asb-tui record/replay and comparison tutorials

Create TUI tutorials for recording and strictly replaying LLM API responses, then comparing two or
more agents from the same benchmark. Cover cassette privacy/provenance, offline replay, exact
benchmark identity, run selection, failed-result retention, and conservative incomparability.

CI validates routes, actions, schemas, command snippets, and synthetic reports only. No LLM,
provider, benchmark, or network operation is allowed.
