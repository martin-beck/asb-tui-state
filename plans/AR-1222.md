# AR-1222: asb-tui benchmark run and shared-agent configuration tutorials

Create TUI tutorials for starting one benchmark run and for extending the configured agent set while
applying the same explicit provider/model/benchmark configuration to all selected agents. Cover
selection, confirmation, progress, cancellation/recovery explanations, atomic incompatibility
handling, and configuration origins.

CI checks the action/route syntax and synthetic lifecycle/report fixtures without launching ASB,
agents, providers, or a benchmark.
