# AR-1333 — User-driven provider setup and configuration draft

## Scope

Extend the standalone asb-tui wizard so a user can select only supported
providers, models, agents, authentication modes, defaults, and benchmark
settings, then review and persist a complete configuration draft. The flow must
use credential references or development fixtures only; it must never ask the
user to paste a secret into the TUI.

## Dependencies

Depends on AR-1325, AR-1328, AR-1329, and AR-1327.

## Acceptance

- Every selectable provider, model, and agent comes from a bounded validated
  catalog; unsupported combinations are rejected before persistence.
- The wizard exposes visible backtracking, cancellation, contextual help, and
  a final review of every selected value.
- Apply atomically creates/updates the user configuration through a documented
  local seam, with no raw credentials, paths, or environment values in output.
- Development fixtures remain usable without network, credentials, or an
  authenticated production router; live authorization is future qualification.
- Restarting after cancellation or a failed apply does not replay stale drafts.
