# AR-1324 — Install and broker onboarding

## Scope

Make the standalone TUI install path discoverable and self-checking. Consume
the verified ASB bundle/install contract, negotiate the local broker/control
connection, and present one recovery action for missing, stale, or incompatible
components without asking users to edit paths or read protocol documentation.

## Dependencies

Depends on AR-1200 and the paired ASB install/bootstrap AR-1441.

## Acceptance

- A clean supported install launches the TUI and reports ASB/TUI/catalog
  compatibility before showing configuration controls.
- Missing bundle, broker, terminal, or protocol support is explained with a
  selectable repair/retry/exit choice; no unsafe fallback is attempted.
- Signed bundle, private socket, version pin, and rollback evidence are tested.
