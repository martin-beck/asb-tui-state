# AR-1220: asb-tui first-run and first-agent tutorial

Create the standalone TUI tutorial for first launch, initialization, adding the first agent, and
configuring its provider/agent connection. Explain keyboard routes, configuration ownership,
secret-reference boundaries, reconfiguration, and the expected readiness view.

Consume the ASB tutorial contract from AR-1210 and the authenticated catalog/lifecycle interfaces;
keep all examples synthetic. CI validates TUI actions, routes, command snippets, schema references,
and expected states without launching a provider, contacting an LLM, or performing a benchmark.
