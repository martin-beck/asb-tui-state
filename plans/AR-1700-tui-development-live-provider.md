# AR-1700 — TUI development live-provider setup

Add a selection-driven wizard flow for agent(s), provider, authentication
method, API-key environment reference, and provider-supported model. Refresh
the OpenRouter catalog from the connected provider when possible, explain
offline/mock versus live execution, persist only non-secret configuration, and
show a warning-only result when the development key is missing. Verify restart,
edit-all/edit-selected, malformed configuration recovery, and JSON parity.
