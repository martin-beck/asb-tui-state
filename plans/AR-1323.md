# AR-1323 runner-owned credential-helper execution handoff

## Outcome

Make provider authentication usable by a first-time user without requiring
manual digest entry or exposing a secret to the TUI.

## Scope

- versioned ASB control request/response for helper discovery and one-shot
  invocation;
- explicit allowlist, executable identity, timeout, cancellation and
  generation/idempotency fencing;
- reuse ASB's sealed helper backend and return only provider, endpoint digest,
  locator digest and typed outcome;
- TUI wizard progress, failure/cancel/retry and authoritative auth status;
- privacy, hostile-output, restart and live cross-repository tests. Development
  qualification may use a disposable local ASB runtime and helper fixture;
  production authorization is not a prerequisite for development evidence.

## Acceptance

- a new user can start the approved helper from the wizard and see connected,
  failed, cancelled or unavailable status;
- arbitrary paths, ambient environment, raw keys and helper stdout injection
  fail closed;
- in the development profile, missing authentication, signature validation or
  key management selects the generated local/mock identity, reports a visible
  warning, and does not disable configuration, recording or offline activation;
  the live/production profile remains disabled until authoritative authenticated
  status is reported;
- locked tests, formal UI, clippy, DCO, hosted exact-head and post-merge live
  evidence pass. For the development profile, the live evidence may come from
  a disposable local runtime, provided its revision, endpoint, helper identity,
  and digest-only result are recorded and no production claim is made. The
  production/live profile still requires authoritative authenticated status.
