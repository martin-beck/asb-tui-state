# AR-1323 runner-owned credential-helper execution handoff

## Outcome

Make provider authentication usable by a first-time user without requiring
manual digest entry or exposing a secret to the TUI.

## Scope

- versioned ASB control request/response for helper discovery and one-shot
  invocation;
- explicit allowlist, executable identity, timeout, cancellation and
  generation/idempotency fencing;
- reuse ASB's sealed helper backend and return only provider, endpoint digest,
  locator digest and typed outcome;
- TUI wizard progress, failure/cancel/retry and authoritative auth status;
- privacy, hostile-output, restart and live cross-repository tests.

## Acceptance

- a new user can start the approved helper from the wizard and see connected,
  failed, cancelled or unavailable status;
- arbitrary paths, ambient environment, raw keys and helper stdout injection
  fail closed;
- configuration, recording and offline activation remain disabled until the
  runner reports authoritative authenticated status;
- locked tests, formal UI, clippy, DCO, hosted exact-head and post-merge live
  evidence pass.
