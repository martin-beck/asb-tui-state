# AR-1677 — Channel-aware TUI quickstart and release gate

Make one short selection-driven journey accept the default `dev` or an explicit
channel, configure provider/model and agents, run workloads, record responses,
replay offline, compare results, and explain the source/build identity. The
release receipt must include exact ASB/TUI heads and network-denial evidence.

Interactive claims require a real PTY; non-PTY limitations must be recorded as
runner constraints rather than hidden or misclassified as product success.
