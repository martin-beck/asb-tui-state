# AR-1335 — ASB configuration materialization and preflight

## Scope

Materialize the reviewed provider, agent, model, benchmark, and measure
selection into all configuration files required by the supported asb command
contract. Provide a visible preflight screen showing what will be written and
what is development-only, then validate the generated files before execution.

## Dependencies

Depends on AR-1333 and AR-1334.

## Acceptance

- The TUI generates complete bounded configuration documents from typed state;
  users do not copy arguments, paths, or file fragments manually.
- Writes are private, atomic, idempotent, and recoverable; failed validation
  leaves the previous configuration untouched.
- Generated documents contain no raw API keys or secret material and have
  deterministic digests suitable for run binding.
- Preflight rejects unsupported provider/model/agent/measure combinations,
  stale catalog generations, and conflicting file ownership before launch.
- Tests cover fresh setup, edit/reapply, cancellation, corrupt existing files,
  partial-write recovery, and development fixture operation without ASB network
  access.
