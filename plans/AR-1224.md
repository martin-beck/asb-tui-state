# AR-1224: Cross-repository tutorial syntax and freshness gate

Add the asb-tui CI gate that discovers every tutorial and validates its TUI routes, action IDs,
ASB command snippets, protocol/schema references, expected states, and dependency pins against the
current standalone UI and ASB contracts. Reuse or consume the versioned validator from ASB AR-1210
without copying private history.

The gate must run in a clean offline environment, use synthetic fixtures, reject removed/renamed
commands and UI actions, and prove that no tutorial step is executed. It must produce deterministic,
privacy-safe diagnostics and cover both the first-run wizard and the full run/record/replay/compare
journeys.
