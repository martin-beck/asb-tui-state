# AR-1198: Contextual-help catalog CI hardening

## Scope

Repository: `martin-beck/asb-tui`. Own only the document-backed help schema, lookup contract,
coverage/privacy validators, tests, and CI integration. Do not add ASB backend behavior or move
any TUI rendering/application code into ASB.

## Work sequence

1. Review PR #88 at immutable exact head `74e05d8bb262260f1cef2375ca70800b208bedb6` and verify
   its parent AR-1037/#61 and catalog AR-1036/#60 assumptions.
2. Enumerate every current UI element, action, state/context, visible hotkey, wizard route, landing
   route, configuration route, report/check route, and error/recovery route from the executable UI
   model and module inventory.
3. Define and validate the extensible document structure: stable IDs, context predicates,
   meaningful text, action kind, keyboard affordance, accessibility/plain-text form, and safe
   fallback/error behavior. Reject unknown fields and undocumented IDs deterministically.
4. Add CI checks that compare the help catalog with UI_OWNERS, UI modules, the formal model,
   executable transitions, and rendered element/action inventories. Ensure adding an element or
   action without meaningful help fails CI.
5. Add negative, privacy, schema, lookup, deterministic-order, and complete-coverage tests, then
   run the locked focused and full Rust/Python gates.
6. Obtain independent exact-head review, verify SSH signature/DCO and hosted exact-head CI, and
   record the immutable evidence before promotion or merge.

## Acceptance

- All performable actions and visible UI elements have meaningful context-sensitive helper text.
- New UI IDs/actions cannot bypass coverage because CI cross-checks the authoritative inventories.
- Help documents are extensible, deterministic, privacy-safe, and fail closed on malformed or
  undocumented content.
- Tests cover every current route and representative state transitions, including wizard,
  landing, configuration, reports, errors, hotkeys, and recovery.
- No ASB renderer/Ratatui/application code is introduced; all product behavior remains standalone.
- Exact-head, signature/DCO, independent review, and hosted CI evidence is recorded.
