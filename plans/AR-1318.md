# AR-1318 implementation plan

## Outcome

Update asb-tui's authenticated agent-catalog codec and projections to the
current ASB catalog contract without weakening strict schema validation.

## Scope

Own only the TUI control codec, generated/fixture schemas, live projection,
wizard catalog adapter, formal model and tests. Add the required signer,
SBOM, license and target provenance fields with exact bounds and preserve
version negotiation/fail-closed unknown-field handling.

## Acceptance

- Current ASB catalog fixtures round-trip and validate at the negotiated
  version; old unsupported shapes are rejected explicitly.
- The wizard shows only entries whose package/provenance and availability are
  valid, with no paths, secrets or provider payloads.
- Generated state/help/inventory artifacts, focused formal tests, locked
  clippy/tests, exact-head CI and post-merge checks pass.
