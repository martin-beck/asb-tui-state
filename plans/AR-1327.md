# AR-1327 — Cross-repository first-class journey qualification

## Scope

Qualify the pinned ASB/asb-tui journey from install through wizard, benchmark,
offline replay, and comparison. Keep a compact support matrix and release gate
with credential-free local evidence and explicit live-evidence limits.

## Dependencies

Depends on AR-1324, AR-1325, AR-1326, and paired ASB AR-1444.

## Acceptance

- A disposable user completes the supported journey through visible choices,
  with no documentation lookup or manual path editing.
- Version, catalog, bundle, and protocol mismatches stop before execution and
  offer one actionable recovery path.
- Evidence labels and support matrix are consistent between CLI and TUI.
